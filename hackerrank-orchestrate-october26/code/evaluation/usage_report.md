## How to read the numbers

- *Live calls* are provider calls made during the reported run. *Cached answers* were served from the on-disk response cache (`.llm_cache/`) and cost no provider call in this run; their tokens are the tokens the same answers cost when they were first fetched. Token and cost totals below include both, so they describe what the pipeline's answers cost in total, not only what this run spent.
- The LLM is used in two places only: classifying the request text (`request_intent`, one short call per distinct text) and reading the application screenshots in the evidence (`image_extraction`, one call per image, loaded once for all requests). Everything else is deterministic code.
- Request texts decided by the keyword fallback make no model call (0 of 518 in this run).
